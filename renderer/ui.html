书写语法与快捷键

章节与小节

右键选「插入章节」。每个新章从下一页开始。在章内用 # 写一级小节，如 2.1，用 ## 写二级小节，如 2.1.1。

Ctrl Alt 1–6 设置小节层级，Ctrl Alt 0 恢复正文。

公式

$E=mc^2$ 为行内公式。输入一个 $ 会自动配对。Alt = 也可插入一对 $，在中间输入后按回车转成 $$…$$ 独立公式。

图片与引用

把光标放到需要的位置，右键添加图片或引用。Ctrl Shift C 打开 Zotero 文献库。
